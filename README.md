#Catalogo_Papeleria_JavaFX

Desarrollar el catálogo de productos de la papelería Campus con JavaFX, JDBC y PostgreSQL. Integrar listado real, búsqueda y filtros, operaciones CRUD, validaciones y manejo de errores. El documento del laboratorio contiene 12 registros iniciales, resultados esperados, pruebas de validación y rúbrica analítica.
